# Install the Lumen SDK

The SDK supports Python 3.10 and newer.

## 1. Create a virtual environment

```bash
python -m venv .venv
source .venv/bin/activate
```

## 2. Install

```bash
pip install lumenpay
```

## 3. Check the install

```bash
python -c "import lumen; print(lumen.__version__)"
```

This prints the installed version number.
