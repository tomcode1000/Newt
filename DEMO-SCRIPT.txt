Do NOT name the builder in the video. Do NOT show .env or any API key.

------------------------------------------------------------------------
A. WHAT THE VIDEO MUST PROVE (judges' checklist)
------------------------------------------------------------------------
1. It is a real agent: plans, runs steps, reads errors, decides whose fault.
2. It recovers: a failed action and what it did next.
3. It checks itself: a fix only counts after a re-run from zero.
4. neatlogs, Entire and cfo.ai are each used, on screen.
5. A number: fix-everything baseline vs Newt, same 8 pages.
